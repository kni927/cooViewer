## Release notes

```markdown
## v1.6.8
- The page bar shows where you are, such as 9-10/20. Preferences ▸ Appearance ▸ Page Bar ▸ Number puts it in the bar, above it, in the title bar, or turns it off.
- The page number display now shows file names, each with its resolution: 009.jpg (1400x2000) | 010.jpg (1400x2000). It can instead appear in a bar along the bottom of the window, with each name under its page.
- The page bar is a little taller by default.
- File ▸ Export… (⇧⌘E) saves all pages, or pages such as 2-3,5, as an uncompressed CBZ holding the original image files unchanged. Not available for PDF books.
- The resolution bar no longer slides off the left edge when it shares a corner with short file names.
```

If verification cannot confirm an item, tell the owner before replacing the body.
