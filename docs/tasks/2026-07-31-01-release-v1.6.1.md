### Step 1 — dSYM upload in CI

**Finding beyond what the task anticipated:** `DEBUG_INFORMATION_FORMAT` was
not set *anywhere* in the project (a legacy-style `.pbxproj`), so the task's
literal instruction ("confirm DEBUG_INFORMATION_FORMAT is dwarf-with-dsym")
had no setting to inspect. The actual gate turned out to be a different,
older setting: the `cooViewer` target's `Deployment` configuration had
`GCC_GENERATE_DEBUGGING_SYMBOLS = NO`. Verified empirically rather than
inferred — with only that setting present, a clean build produced **no
`.dSYM` at all**:

```
$ xcodebuild ... -configuration Deployment build   # unmodified project
$ find "$BUILD_TMP/sym" -iname "*.dSYM"
(nothing)
```

Setting `GCC_GENERATE_DEBUGGING_SYMBOLS = YES` *and*
`DEBUG_INFORMATION_FORMAT = dwarf-with-dsym` together produced a working
dSYM:

```
$ find "$BUILD_TMP/sym" -iname "*.dSYM"
.../bt-after/sym/Deployment/cooViewer.app.dSYM

$ dwarfdump --uuid .../cooViewer.app/Contents/MacOS/cooViewer

$ dwarfdump --uuid .../cooViewer.app.dSYM
```

**Where `xcodebuild` writes the dSYM, and the `build/` decision.** CI does
not use the repo's local-dev SYMROOT-redirect convention — it runs a plain
`xcodebuild -configuration Deployment` with no path overrides, so *all*
Xcode output, intermediates included, already lands directly under the
repo's `build/` on the runner (pre-existing, confirmed by reproducing CI's
exact invocation locally):

```
$ xcodebuild -project cooViewer.xcodeproj -configuration Deployment build
$ find build -iname "*.dSYM"
build/Deployment/cooViewer.app.dSYM
```

So the dSYM sits right next to `cooViewer.app` in CI's own ephemeral
`build/`, with no path change needed to reach it. This does **not**
contradict the documented local-dev convention ("`build/` holds only the
final app"): that convention's own `cp` step only ever copied
`cooViewer.app`, never a dSYM, and still doesn't — confirmed by rebuilding
with the local SYMROOT-redirecting command and checking local `build/`:

```
$ ls -A build/
cooViewer.app
```

Recorded as a decision in `docs/DECISIONS.md`,
"Deployment configuration now generates a dSYM…".

Workflow diff (`.github/workflows/xcode-build-and-release.yml`):
