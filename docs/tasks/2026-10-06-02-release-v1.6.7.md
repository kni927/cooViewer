## Release notes

```markdown
## v1.6.7
- Page numbers set to hide automatically now reliably reappear when you move the mouse.
- The resolution has its own section in Preferences: show it in the page number, or in its own bar with its own position and font.
- Non-solid RAR/CBR books whose pages are stored out of order read much faster.
- Solid RAR5 books: jumping and paging back are much faster, because pages are decoded ahead into a temporary cache.
- Paging back in a solid book no longer freezes the window while the page is decoded; the page appears when ready.
- Loading a book no longer blocks your other windows, and quitting during a load cancels it.
- An empty or unreadable book is reported with a message instead of opening as a blank page.
- You can quit while the All Bookmarks browser is open.
- The mouse "Skip" action no longer also turns the page.
- Spreads no longer lose up to one point at the right and top edges of pages whose size is not a whole number of points.
- Fixes for book handling: Save Image onto the page's own file no longer deletes it; opening another book while one is loading or asking for a password is refused; RAR links and duplicate file names no longer shift pages; a wrong ZIP password is always detected; one unreadable nested archive no longer stops the whole book.
- Stability fixes in page prefetching.
```

If verification cannot confirm an item in these notes, tell the owner before
replacing the release body; the owner decides whether to drop or reword it.
