### Changes

1. **Preferences ▸ OK keeps a book's reading direction (75ec8b7).**
   `-[BookWindowController setPreferences]` applied the `ReadMode` default
   whenever the book's mode differed from it and `currentBookSetting` had no
   `readMode`; `-changeReadMode:` records the menu choice there only with
   Remember book settings on (off by default), so every OK reset it. New
   ivars `takenDefaultReadMode` / `takenDefaultSortMode` record the default
   the window last took (at init, book open and Delete Settings); OK now
   applies a default only when the default itself changed and the book
   still follows the old one. Predates v1.6.8 (same logic in the tag,
   traced to the original code).
2. **Overlay follows every frame change (3ac1d75).** The `AccessoryWindow`
   was resized only from `-[CustomWindow setFrame:display:]`, which macOS
   tiling bypasses. `CustomWindow` now also observes its own
   `NSWindowDidResizeNotification` / `NSWindowDidMoveNotification`;
   `-setAccessoryWindowFrame` returns early when the frame is already right.
   Predates v1.6.8.
3. **Readable font previews (473ae06).** The three preview fields are now
   plain bordered fields with an opaque fill: the HUD background composited
   over the View background colour, as the HUD looks over the viewer. The
   View background popup gets an action so the previews follow it. Text
   colour unchanged. The exact cause of the near-white field (bezel or
   window fill showing through the translucent HUD colour) is inferred, not
   proven. Predates v1.6.8.
4. **Build tooling.** f372df5: `vendor/build-libs.sh` runs
   `lipo "$lib" -verify_arch "$arch"` once per architecture (the current
   `lipo` takes one architecture per call; a missing one returns 1). The
   check dates from v1.4.0 and broke with a newer Xcode. cffa962: every
   `PlistBuddy Delete` in the "Configure helper Info.plist" phase ends in
   `|| true`, and `CFBundleDisplayName` / `LSUIElement` are deleted before
   their `Add`, so the phase can run again on an already edited plist.
   Predates v1.6.8.

Bugs found and fixed along the way:

  the menu and jumped it to page 0 (same cause as item 1; fixed in 75ec8b7).
