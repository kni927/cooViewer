## Release notes

```markdown
## v1.6.6

- Fixed crashes when closing a window during a slideshow, after editing a
  bookmark, or while its thumbnails are still loading.
- Clicks, keys and page-number input in an empty window (File ▸ New Window)
  no longer trigger page actions.
- Filter settings now apply only to the window they were set in, and the
  filter panel follows the front window.
- Solid RAR4 archives, which cooViewer cannot read, now show a clear message
  instead of opening as broken pages.
- Archives with malformed contents are handled more safely, including very
  long file names, nested archives with unsafe paths, files with the wrong
  extension, and oversized entries.
```

If verification step 6 below cannot confirm the thumbnail-loading case, tell
the owner before replacing the release body; the owner decides whether to
drop "or while its thumbnails are still loading".
