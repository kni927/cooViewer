## Release notes

```markdown
## v1.6.4

- Opening a book from Finder when cooViewer is not running no longer adds a
  window next to the ones macOS restores. The book now opens in the front
  restored window, the same as when cooViewer is already running. A book
  that a restored window is already showing still just brings that window
  forward.
- cooViewer now requires macOS 12 Monterey or later. Its Quick Look
  extensions and the "cooViewer (New Window)" helper already did.
- Added diagnostic logging for how open requests are routed to windows, to
  help investigate window-related problems. File names are not logged.
```

## Release procedure

is the procedural precedent.

1. Push `main` to `origin`.
2. Push the `v1.6.4` tag. CI (`.github/workflows/xcode-build-and-release.yml`)

   or notarization fails, stop and report. Never work around Gatekeeper.
4. Set the GitHub Release body to the release notes above, if CI did not.
5. Update the tap formula: version, URL, sha256. If the formula declares a
   macOS requirement (`depends_on macos:`), raise it to Monterey; if it does
   not, report that rather than adding one unasked.
