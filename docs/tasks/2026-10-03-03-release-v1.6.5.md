## Release notes

```markdown
## v1.6.5

- Hold Shift while opening a book from Finder (double-click, Open With, or ⌘↓)
  to open it in a new window. Without Shift, the front window is reused as before.
- Drop books, folders or image files onto a window to open them there. A book
  that is already open just brings its window forward; when several files are
  dropped, the first opens in that window and the rest in new windows.
- File ▸ New Window (⌘N) opens an empty window.
- The page resolution is now shown on single pages too, and can be shown in
  its own bar (Preferences: Off / In page number / Separate bar).
- The "cooViewer (New Window)" entry in Open With now has the app icon.
```
