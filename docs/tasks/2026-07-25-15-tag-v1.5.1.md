# TASK: Tag v1.5.1 (version bump only, no release)

## Scope

Bump the app version to 1.5.1 and create a git tag marking the point where
encrypted ZIP password support landed. This is a version marker only —
no notarization, no GitHub Release, no Homebrew tap update. The full
release process is deferred to v1.5.2, once cvbdl QuickLook support is
added, to avoid notarizing twice.

## Steps

1. Update `CFBundleShortVersionString` (and `CFBundleVersion` if the
   project increments it separately) to `1.5.1` across all targets that
   carry a version (main app; check whether the extensions share or track
   it independently).
2. Confirm `docs/DEV_LOG.md` already reflects the encrypted ZIP milestone
   from task 10; if the entry doesn't reference a version number, add
   "(v1.5.1)" to it now that the number is known. Do not duplicate the
   entry.
3. Build and confirm the version shows correctly in About / bundle info.
4. Commit the version bump.
5. Create an annotated tag: `git tag -a v1.5.1 -m "..."` — summarize
   restored password-protected ZIP support (with Japanese-password
   support) as the tag message.
6. Push the commit and the tag: `git push origin main` and
   `git push origin v1.5.1`.

## Explicitly out of scope

- No notarization.
- No GitHub Release object or release notes page.
- No Homebrew tap update — the tap continues serving the last released
  version until v1.5.2.

## Verification

- `git tag -l` shows `v1.5.1` locally and on origin.
- Built app reports version 1.5.1.
- `git status` clean.

## Notes

- Do not create a GitHub Release from this tag. If `gh release create` or
  similar is available, do not invoke it here.
